# TEXTFILES underground archive

WAYKEEPER found the already downloaded TEXTFILES.COM mirror at the neighboring
HRF-H2 deployment. It contains **33,009 files / 1,108,596,438 source bytes** and
a 64-bucket COUNTER-SVX-1 search index. The archive is referenced in place so a
second 1.2 GB copy is not created.

`scripts/import_textfiles_survival.py` imports 21 survival-relevant documents
plus a complete-archive index record into F9. The curated group includes field
planning, homesteading, water, shelter, fire, repair, trail food, clothing,
travel, communications, brewing, ginger beer, and one requested historical
home-alcohol/distillation file.

Every imported page is visibly marked:

```text
TEXTFILES SOURCE // UNDERGROUND, HISTORICAL, UNVERIFIED + RIGHTS UNCLEARED
```

The complete archive is not injected into Guide search. Doing so would let
33,000 unreviewed and potentially malicious, illegal, offensive, dangerous, or
copyrighted texts outrank reviewed emergency sources. The full archive and its
index remain preserved; the curated readers are local-personal adaptations and
must not be redistributed without rights review.

Set `WAYKEEPER_TEXTFILES_ARCHIVE` to relocate the complete archive.
